## 🚀 Featured project

### AI-Powered Pricing System — *in production*

Turns free-text price lists sent by suppliers into automatic store updates.

```
WhatsApp  →  Google Gemini (LLM)  →  n8n  →  WooCommerce (REST API)
```

- 🧩 Gemini parses free-text messages into structured data (model, color, storage, price)
- 💰 Compares prices across multiple suppliers — the lowest always wins
- 🆕 Automatically creates product variations for new models
- 🔔 Sends WhatsApp reminders to suppliers who haven't sent a list in 2+ days
- ⏱️ Replaced a daily manual process
